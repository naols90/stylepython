Slide 6 🌈 Colorama – simplest cross‑platform method

🔧 Installation: pip install colorama

from colorama import Fore, Back, Style, init
init(autoreset=True) # automatically reset after each print

print(Fore.RED + "This is red text")
print(Fore.GREEN + "Green success message!" + Style.RESET_ALL)
print(Back.YELLOW + Fore.BLACK + "Caution: yellow background, black text")
✅ Fore.RED, Fore.BLUE, Fore.CYAN ...
✅ Back.RED, Back.GREEN, Back.YELLOW ...
✅ Style.DIM, Style.BRIGHT
✅ init(autoreset=True) recommended

💡 Colorama makes ANSI work even on old Windows terminals. Perfect for Chromebook / Linux / Mac too.

Slide 7 ✨ termcolor – extra formatting attributes

📦 pip install termcolor

from termcolor import colored

text = colored("Hello Python!", color="cyan", on_color="on_magenta", attrs=["bold"])
print(text)
print(colored("Success", "green", attrs=["reverse"]))
print(colored("Error", "red", "on_white"))
  • color="red" or "blue", "yellow", "green" ...
  • on_color="on_red" for background
  • attrs=["bold", "underline"] additional styling
Slide 8 📝 Practical example – colored status messages
def print_status(msg, status="info"):
    if status == "success":
        print(f"\033[92m✅ {msg}\033[0m")
    elif status == "error":
        print(f"\033[91m❌ {msg}\033[0m")
    elif status == "warning":
        print(f"\033[93m⚠️ {msg}\033[0m")
    else:
        print(f"\033[94mℹ️ {msg}\033[0m")

print_status("File saved successfully", "success")
print_status("Network connection lost", "error")
print_status("Low disk space", "warning")
print_status("Server is running", "info")

🏆 Result Clear visual distinction between message types.

Slide 9 🖍️ Background color – complete examples (ANSI + Colorama)
# ANSI background examples
print("\033[44m\033[37m Title with blue background, white text \033[0m")
print("\033[42m\033[30m Green background, black text \033[0m")

# Using Colorama (easier to read and maintain)
from colorama import init, Back, Fore, Style
init(autoreset=True)
print(Back.RED + Fore.WHITE + "CRITICAL ERROR" + Style.RESET_ALL)
print(Back.GREEN + Fore.BLACK + "Operation completed successfully")

🌟 Backgrounds are great for banners, important notifications, and interactive CLI tools.

Slide 10 ⚖️ Method comparison – which one to choose?

Slide 11 🌍 Working with any UTF‑8 text (Amharic, Arabic, etc.)
# Unicode text works perfectly with all color methods

from colorama import Fore
print(Fore.CYAN + "Colorful output for any language" + Fore.RESET)

💡 Make sure your terminal font supports the script you're using. Modern terminals (Windows Terminal, GNOME Terminal, iTerm2) fully support UTF‑8.
